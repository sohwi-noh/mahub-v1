# ktds-sdd 문서 가이드

처음 보는 팀원은 루트 `README.md`를 먼저 보고, 세부 운영 절차는 `docs/operations/`의 문서를 봅니다.

## 먼저 볼 순서

1. `README.md`: 실행 진입점과 문서 인덱스.
2. `docs/operations/README-ECC.md`: 하네스 규칙 레이어. ECC rules, skills, Java/TypeScript/Web 기준.
3. `docs/operations/README-SYMPHONY.md`: AI agent 오케스트레이션 레이어. Linear queue, Symphony 실행, 이슈별 작업공간 생성과 repo/branch 준비 방식.
4. `docs/operations/README-LINEAR.md`: Linear 작업 로그와 hook 경계.


이 디렉터리는 안내만 담습니다. 실제 운영 기준은 `docs/operations/`와 `.ecc/rules/**`를 기준으로 봅니다.
