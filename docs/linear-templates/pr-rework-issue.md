- [ ] 기존 PR을 닫을지 유지할지 판단합니다.

- [ ] 새 PR을 `main` 대상으로 발행합니다.

## 완료 기준

- 기존 PR 또는 원 Linear 이슈에 기각 사유가 남아 있습니다.
- 이 이슈와 새 PR이 연결되어 있습니다.
- 원 Linear 이슈, 원 PR, 새 연결 이슈의 관계가 본문 또는 댓글에 남아 있습니다.
- 새 PR은 `main`을 base로 사용합니다.
- 재작업 범위와 제외 범위가 PR 설명에 반영되어 있습니다.
